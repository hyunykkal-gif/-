# 🍑 복숭아 다이어리

다이어트 기록용 웹 다이어리입니다. `index.html` 한 파일로 동작하며, 기록은 서버로 보내지 않고 그 기기의 브라우저(localStorage)에만 저장됩니다.

## 아이폰에서 쓰기

1. Safari로 아래 주소를 엽니다.
   - https://hyunykkal-gif.github.io/-/
2. 공유 버튼 → **홈 화면에 추가**를 누르면 앱처럼 바로 열립니다.

## 기능

- 현재·목표 체중과 달성률, 연속 기록, D-day
- 오늘의 체중·체지방률, 식단(아침/점심/저녁/간식), 물 섭취, 운동, 기분·메모
- 체중 변화 그래프 (7일 / 30일 / 전체)
- JSON 백업·복원, CSV 내보내기, 샘플 데이터

기기를 바꾸거나 브라우저 데이터를 지우면 기록이 사라지므로, 가끔 JSON 백업을 받아 두세요.
